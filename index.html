Four KV260s, one LLM

Llama-3.2-1B-Instruct (Q4_0, 663 MiB) decoded by four Kria KV260 boards working on one stream: each board streams a quarter of the weights through its own FPGA engine, and they exchange partial sums over a gigabit switch. Every token you see was computed by all four.

What is behind this page

The API is OpenAI-compatible (/v1/chat/completions, streaming). It runs on board 1 of four AMD Kria KV260s; the boards run a tensor-parallel runtime on a custom int4 weight-streaming engine in each FPGA's fabric (Vitis HLS, 250 MHz, four AXI ports at ~11.6 GB/s). One board alone does ~10 tokens/s; four together ~20. First-token latency is the prompt being processed one token per engine pass, so long prompts wait longer. One prompt is served at a time, in arrival order, so the one stream gets the full rate; if someone else is chatting, yours queues (at most 8 wait).

Use it from any OpenAI client with base_url = <API>/v1 and any API key.
